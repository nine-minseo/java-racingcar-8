# java-racingcar-precourse

우테코 8기 백엔드 - 프리코스 2주차 과제: 자동차 경주

- [x]  사용자로부터 자동차 이름과 시도할 횟수를 입력받는다.
    - [ ]  쉼표(,)를 기준으로 자동차 이름을 구분한다.
        - 쉼표가 아닌 문자를 입력할 경우 자동차 이름 1개로 간주한다.
        - [ ]  자동차 이름을 입력하지 않을 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션을 종료한다.
    - [ ]  자동차 이름을 5자 이하로 입력받는다.
        - [ ]  5자를 초과하여 자동차 이름을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션을 종료한다.
    - [ ]  시도할 횟수를 입력하지 않을 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션을 종료한다.
- [ ]  자동차 경주 게임을 진행한다.
    - [ ]  0에서 9 사이에서 무작위 값을 구한다.
    - [ ]  무작위 값이 4 이상일 경우 자동차를 전진한다.
    - [ ]  참여자 수만큼 반복한다.
    - [ ]  실행 결과를 출력한다.
    - [ ]  시도 횟수만큼 반복한다.
- [ ]  한 명 이상의 우승자를 쉼표(,)로 구분하여 출력한다.
