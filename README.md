# java-racingcar-precourse

### 우테코 8기 백엔드 - 프리코스 2주차 과제: 자동차 경주

### 1. 입력, 유효성 검사

- 자동차 이름 입력
    - [x]  경주할 자동차 이름을 쉼표(,)로 구분하여 입력받는다.
- 자동차 이름 유효성 검사
    - [x]  자동차 이름이 비어있거나 공백인 경우
        - [ERROR] 입력이 비어있습니다.
    - [x]  자동차 이름이 5자를 초과하는 경우
        - [ERROR] 자동차 이름은 5자를 초과할 수 없습니다.
    - [x]  자동차 이름에 중복이 있는 경우
        - [ERROR] 자동차 이름은 중복될 수 없습니다.
    - [x]  쉼표로 구분했을 때 이름이 없는(공백인) 경우 (예: pobi,,woni)
        - [ERROR] 입력하지 않은 자동차 이름이 있습니다.
- 시도 횟수 입력
    - [x]  시도할 횟수를 입력받는다.
- 시도 횟수 유효성 검사
    - [x]  시도 횟수가 비어있거나 공백인경우
        - [ERROR] 입력이 비어있습니다.
    - [x]  시도 횟수에 숫자가 아닌 문자가 포함된 경우
        - [ERROR] 숫자가 아닌 문자가 포함되어 있습니다.
    - [x]  시도할 횟수가 양수가 아닌 경우
        - [ERROR] 양수만 입력할 수 있습니다.

### 2. 게임 진행

- [x]  0~9 사이의 무작위 값을 구한다.
- [x]  무작위 값이 4 이상일 경우, 자동차를 1칸 전진한다.
- [x]  시도 횟수만큼 모든 자동차에 대해 전진/정지를 반복한다.

### 3. 출력

- [x]  차수별 실행 결과를 출력한다. (자동차의 이름과 전진한 횟수를 하이픈(-)으로 출력한다.)
- [x]  모든 라운드가 끝난 후, 우승자를 판단한다.
- [x]  우승자를 쉼표(,)로 구분하여 출력한다.
